# OpenSeal
### Sign Documents Online

I'm trying to make an open-source alternative to DocuSign (It's an online document signing platform). But I find it's onboarding a bit of hassle and was unable to adapt in my dashboards for agency.

It's only build on FastAPI and Vanilla JS (for now).

## Test it yourself..

1. Create a virtual environment: `python -m venv .venv`
2. Activate the env: `.\.venv\Scripts\activate` (Windows) or `source .venv/bin/activate` (Mac/Linux)
3. Install dependencies: `pip install -r requirements.txt`
4. Run the server: `python main.py`

Visit to `http://localhost:8000/` to view the working app (prototype for now ;)
